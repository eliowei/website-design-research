# Butter 設計分析

- **網址**：https://www.butter.video/
- **研究日期**：2026-10-01
- **研究頁面**：首頁
- **類型**：SaaS 產品落地頁（線上影片剪輯工具）
- **來源**：Awwwards Site of the Day（2026-09-28），作者 ToyFight
- **Awwwards 評分**：7.5／10
- **技術**：React、WebGL、P5.js（依 Awwwards 標示）；內容管理用 Prismic（從圖片網址判斷）

> **研究範圍限制**：研究環境的網路政策擋住了 `butter.video`，所以沒辦法用瀏覽器取得實際的 CSS 數值或觀察動畫。
> 截圖和設計資料都來自 Firecrawl；字級是從截圖量的，屬於約略值。

![桌機版](screenshots/desktop.png)

## 一句話總結

用「冷靜的灰白介面＋大量深色產品截圖＋鮮豔的特效作品」三層對比，
把一個專業剪輯工具包裝成「給創意人玩的玩具」。頁面本身就在示範產品做得出什麼效果。

## 1. 版面結構

桌機版全頁約 17,500px 高，由上到下：

1. **導覽列**：左右兩顆懸浮的圓角膠囊，左邊放 Logo 和選單（Product、Blocks、Templates、Pricing、Blog），右邊放 Login 和「Try for free」。不是傳統的滿版導覽列。
2. **Hero**：上方是 3D 鑰匙圈（品牌吊飾），接著是置中的大標「Engineered for Creativity」、副標和黑色 CTA「Get Started」。背景是由灰到白的漸層。
3. **品牌牆**：「Teams from top brands and agencies build with Butter」，下面是無限輪播的客戶 Logo（Netflix、Airbnb、Canva、SpaceX…共 24 個）。
4. **宣言句**：一整段大字，文字中間穿插小圖示，像貼紙一樣（Nike 勾勾、像素圖案等）。
5. **時間軸展示**：一個深色的時間軸 UI 元件，置中、帶大陰影。
6. **功能區塊×3**：左文右圖、右文左圖交錯排列，每塊都是「等寬小標籤＋大標題＋深色產品介面截圖」。
   - Blocks 素材庫（Inflate、Glow、Focus、Halftone）
   - 客製化面板（旋轉、傾斜、材質等參數）
   - Brand Kit 團隊素材
7. **功能卡片**：四欄卡片 Import → Edit → Enhance → Ship，對應影片製作的完整流程。
8. **三種創作方式**：Remix／Describe／Code，左邊是大圖，右邊是可切換的文字分頁。
9. **範本輪播**：「The best stories are built block by block.」灰底大卡片裡放範本，下面是「Browse All Templates」按鈕。
10. **雙卡片**：「Turn anything into everything.」和「High performance. Totally programmable.」，淺灰底圓角卡片並排。
11. **作品展示**：「Get the look」，左邊是大型特效作品，右邊列出創作者名單。
12. **頁尾**：四欄連結（Explore、Socials、Resources、Legal），下面是一個超大的 Butter Logo，帶彩虹殘影效果。

- 內容寬度：左右邊距約 80px（1920 寬時），內容區約 1760px，很寬。
- 網格：12 欄概念，常用 1:1 雙欄，或四欄卡片。
- 區塊間距非常大（約 300–400px），每個區塊都像獨立的一頁。

**可以學的地方**：功能介紹全部用真實的產品介面截圖，而不是抽象插圖，使用者一看就知道產品長什麼樣子。

## 2. 配色

| 用途 | 色碼 | 使用位置 |
| --- | --- | --- |
| 主背景 | `#FAFAFA` | 頁面主體（截圖實測） |
| Hero 漸層起點 | `#E0E0E0` | Hero 頂部（截圖實測） |
| 頁尾／卡片背景 | `#EDEDED` | 頁尾、淺色卡片、導覽列膠囊（截圖實測） |
| 文字／CTA | `#1E1E1E` | 標題、主要按鈕（截圖實測，Awwwards 色票也是這個值） |
| 產品介面深色 | `#151515` | 時間軸、素材庫等 UI 截圖（截圖實測） |
| 品牌螢光色 | `#00FFD0`、`#FF6EFF`、`#4DC5E5` | Firecrawl 判定的主色、輔助色、強調色，出現在 3D 吊飾、頁尾 Logo 殘影、特效作品 |

- 深色模式：無，但產品截圖本身就是深色介面，在淺色頁面上形成強烈對比。
- 漸層：Hero 背景的灰白漸層；頁尾 Logo 的彩虹殘影。

**可以學的地方**：介面本身幾乎沒有彩度（灰、白、黑），鮮豔的顏色只出現在「產品做出來的東西」上。
這樣顏色就等於產品能力的展示。

## 3. 字型

| 層級 | 字型 | 字級（約） | 字重 | 行高 |
| --- | --- | --- | --- | --- |
| H1 | DieGrotesk | 125px | 400–500 | 約 1.0 |
| H2（區塊標題） | DieGrotesk | 70px | 400 | 約 1.0，字距略緊 |
| 內文 | ABCDiatype | 16–18px | 400 | 約 1.4 |
| 小標籤（如「There's a block for that」） | 等寬字 | 約 12px | 400 | — |
| Logo | 手寫圓潤字（SVG） | — | — | — |

字型資料來自 Firecrawl 的 branding 擷取。兩套都是 grotesk 無襯線字（DieGrotesk、ABC Diatype 是付費字型），
配上等寬字的小標籤，營造「設計工具＋程式」的形象。

**可以學的地方**：大標題用「大字級＋一般字重＋緊字距」，比粗體更精緻。
每個區塊前面都放一個灰色等寬小標籤，這是很好用的層級技巧，能把區塊分得很清楚，又不搶主標題。

## 4. 元件與視覺元素

- **按鈕**：
  - 主要按鈕：`#1E1E1E` 黑底白字，圓角約 8px，小尺寸（約 140×46px）
  - 次要按鈕：淺灰底黑字，附「→」箭頭（View All Features、All Blocks & Templates）
  - 卡片右上角：白色圓形的箭頭按鈕
- **卡片**：大圓角（約 24–32px），分深色（`#151515`）和淺灰兩種，無邊框。
- **導覽列**：懸浮的膠囊，左右分開，半透明淺灰底。
- **行內圖示**：宣言句和功能句子裡嵌入小圖（旋鈕、滑桿的 GIF），文字和圖像混排。
- **3D 物件**：Hero 的金屬鑰匙圈吊飾，每個吊飾都是品牌元素（Butter 字樣、按鍵）。
- **頁尾 Logo**：滿版超大 Logo，帶粉、綠、紫的殘影，像影片的動態模糊。

**可以學的地方**：在句子裡塞入會動的小 UI 元件（旋鈕、滑桿），用一句話同時講功能又展示功能。

## 5. 互動與動態

截圖看不到動態，以下根據 Firecrawl 抓到的內容推測：

- 客戶 Logo 無限輪播（markdown 裡 Logo 清單重複出現，是輪播常見的做法）。
- 範本卡片也是無限輪播（範本清單重複三次）。
- 標題文字在 HTML 裡出現兩次（例如「Engineered for CreativityEngineeredforCreativity」），推測是逐字拆開做進場動畫。
- 「dials」「sliders」旁邊的小圖是 GIF，會動。
- 時間軸元件上有播放指示，推測會隨捲動或自動播放。
- 「Create in 3 ways」推測是點選 Remix／Describe／Code 切換的分頁。

**可以學的地方**：每一段標題都拆字做動畫，能讓長頁面在捲動時一直有新鮮感（推測）。

## 6. 文案與資訊架構

- **主標語**：「Engineered for Creativity」——工程感和創意感並列
- **副標**：「Butter, the first video editor you can build on.」——點出差異化：可擴充的剪輯器
- **語氣**：自信、俐落、帶點玩心（「There's a block for that」）
- **CTA**：「Get Started」「Try for free」「Browse All Templates」「View All Features」
- **資訊順序**：定位 → 社會證明 → 核心概念（Blocks）→ 客製化 → 團隊 → 完整功能 → 創作方式 → 範本 → 規模化 → 作品 → 頁尾
- **核心名詞**：整頁圍繞「block」這個概念反覆強調，從素材庫、品牌套件到範本都是 block

**可以學的地方**：先用一個產品獨有的名詞（block）建立心智模型，再讓每個區塊都回扣這個名詞，敘事會很集中。

## 7. 響應式設計

![手機版](screenshots/mobile.png)

- 導覽列縮成一顆膠囊：Logo 加「⋮」選單。
- H1 從一行拆成兩行，字級縮小，約 36px（360 寬時）。
- 功能區塊從左右交錯改成上下堆疊，文字在上、圖片在下。
- 客戶 Logo 輪播一次只顯示約兩個。
- 宣言句裡的行內圖示在手機上位置留白，可能是載入時機問題，或圖片太小（推測）。
- 全頁約 12,300px 高，很長。

**可以學的地方**：懸浮膠囊導覽列在桌機和手機都適用，只要收起選單項目就好，不需要兩套設計。

## 優點與可改進處

**優點**
- 產品截圖就是主視覺，第一眼就看得出產品是什麼
- 灰白介面和鮮豔作品的對比很強，顏色焦點明確
- 等寬小標籤加大標題的層級系統一致、好讀
- 用「block」貫穿整頁，敘事主軸清楚
- 頁尾的大 Logo 收尾很有記憶點

**可改進處**
- 頁面很長（桌機約 17,500px），區塊間距又大，捲動成本高
- 沒有價格資訊或價格區塊的入口提示（只有導覽列的 Pricing）
- 「Turn anything into everything」和「High performance」兩張卡片用了同一段說明文字，看起來是文案沒寫完
- 「Create in 3 ways」裡 Describe 和 Code 沒有說明文字（至少在擷取的資料中看不到）
- 灰色小字（例如客戶牆標題、卡片說明）對比偏低，可能不符合無障礙標準（推測）
