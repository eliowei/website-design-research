# Stripe vs Notion 首頁設計比較

- **研究日期**：2026-10-01
- **比較對象**：[Stripe](../stripe.com/report.md)（https://stripe.com）、[Notion](../notion.com/report.md)（https://www.notion.com）
- **研究頁面**：兩站首頁（桌機＋手機）
- **使用者關注點**：兩邊都能用的設計模式，以及兩邊設計語言的差異

> 研究範圍：資料只來自 Firecrawl（markdown、branding、截圖），沒有實際量 computed style，字重、行高屬於推測。詳見兩份個別報告。

## 比較表

| 項目 | Stripe | Notion |
| --- | --- | --- |
| 主色 | `#533AFD` 藍紫，配橘→粉→紫漸層 | `#0075DE` 藍，配黑白和暖灰 `#F6F5F4`／`#F9F9F8` |
| 字型 | Sohne（Grotesk），標題細字重，H1 48px／H2 32px | Inter，標題粗體緊排，H1 96px／H2 54px；引言用襯線字 |
| 版面結構 | 左對齊、細格線框住內容欄，約 12 段，桌機約 15,000px | 置中、無格線，約 8 段，桌機約 4,800px |
| CTA 風格 | 4px 小圓角，實心紫＋白底細邊框，帶「›」箭頭 | 8px 圓角，實心藍＋淺藍底無邊框 |
| 主視覺 | 產品 UI 模型＋抽象漸層、粒子 | 真實產品畫面＋手繪線條人物 |
| 整體調性 | 精密、工程感、企業級、用數據說話 | 親切、極簡、文件感、有人味 |

## 共同趨勢（兩邊都能用的設計模式）

1. **Hero 用「一句主張＋雙 CTA」**：主要 CTA 是自助註冊（Get started／Get Notion free），次要 CTA 是業務或另一種註冊方式（Contact sales、Sign up with Google／Request a demo）。兩站都有同時照顧自助型用戶和企業客戶的雙軌轉換路徑。
2. **Hero 下方緊接著 logo 牆**：Stripe 是 7 個彩色 logo，壓在漸層邊緣；Notion 是約 20 個灰階 logo、兩列。兩站都在第一次捲動前就提供社會證明。
3. **用 Bento 格展示產品功能**：Stripe 是 2+1／3 欄的不等寬卡，Notion 是 2+1 卡。兩站的每張卡都是「小標或標題＋產品畫面」，卡上也都有一個動作按鈕（Stripe 是展開，Notion 是 →）。
4. **主視覺是真實產品 UI，不是抽象插圖**：Stripe 放結帳、後台、程式碼模型；Notion 放 Ramp HQ 工作區、Meetings、Dashboard 截圖，都用逼真的假資料。
5. **數據條強化信任**：Stripe 是 4 欄大數字（135+、$1.9T、99.999%、200M+），Notion 是一行跑馬燈（100M users、62% of Fortune 100）。
6. **客戶見證用「人物＋品牌 logo＋一句引言」**：Stripe 有 Hertz 大圖、Mindbody 引言；Notion 有 Cursor／Faire／Ramp 單色濾鏡卡。
7. **頁尾前有一個獨立的結尾 CTA 區**：都是淺色底（Stripe `#F8FAFD`，Notion `#F6F5F4`），重複 Hero 的兩顆按鈕。
8. **克制的單一 CTA 色**：兩站都只用一個飽和色（紫或藍）給主要按鈕，其他元素保持中性。
9. **手機版處理一致**：Hero CTA 改成滿寬堆疊，Bento 卡改單欄，多欄卡改成清單或橫滑。

## 各自的差異化做法（設計語言差在哪）

| 面向 | Stripe | Notion |
| --- | --- | --- |
| 視覺隱喻 | 「基礎設施」：格線、架構圖、粒子光束、深色開發者區，強調規模和可靠 | 「筆記本／文件」：白紙、暖灰卡、手繪塗鴉，強調好用和有人味 |
| 色彩策略 | 大膽漸層當品牌記憶點，再用深海軍藍 `#0D1738` 整區反轉 | 幾乎不用漸層，彩度只出現在插畫、照片濾鏡和 Hero 膠囊 `#D0F4D8` |
| 字體語氣 | 細字重、大字級，同一句標題用兩種顏色（深色主句＋灰藍延伸句） | 粗體、超大字級（96px）、緊字距；用襯線字當「人聲」 |
| 資訊架構 | 依客群分段（企業／新創／平台／開發者），內容多，像產品目錄 | 依使用動作分段（Capture／Find／Automate），內容少，像一份簡報 |
| 互動 | 即時 GDP 計數、多語系／多幣別輪播、手風琴、AI 推薦輸入框 | Hero 動詞輪播（Ship／Think）、附 Pause 鈕的動畫、數據跑馬燈 |
| 元件細節 | 4px 圓角、1px 淡邊框卡、文字連結帶「›」 | 8px 按鈕、約 12px 卡片圓角（推測）、無邊框暖灰卡、黑色圓形箭頭鈕 |
| 手機 Hero | 保留漸層和 H1，拿掉延伸句 | 拿掉產品截圖，改放手繪頭像排；導覽列保留 CTA |

一句話對照：**Stripe 讓人覺得「這東西很強、很可靠」，Notion 讓人覺得「這東西很好用、很友善」。** 兩邊的骨架（Hero→logo→Bento→數據→見證→CTA）幾乎一樣，差異集中在色彩、字重和插畫這幾種「表皮」上。

## 結論：要做類似網站時建議採用的做法

**直接沿用（兩站共通、通用性高）**
- 首頁骨架：Hero（主張＋雙 CTA）→ logo 牆 → 功能 Bento → 數據 → 見證 → 結尾 CTA。
- 主視覺用自家產品 UI 加逼真假資料，不用庫存插圖。
- 只留一個飽和色給主要 CTA，其餘元素維持中性。
- 手機版 CTA 改滿寬堆疊；導覽列像 Notion 一樣保留主要 CTA。

**依產品定位二選一**
- 面向企業、開發者，賣可靠性 → 走 Stripe 路線：細字重雙色標題、格線、深色技術區、依客群分段。
- 面向團隊或個人，賣易用性 → 走 Notion 路線：粗體大標、暖灰底、手繪或品牌插畫、短頁面。

**避免**
- 同時用 Stripe 的漸層和 Notion 的手繪人物，兩種語言會互相打架。
- 學 Stripe 把頁面拉到 15,000px 以上：除非產品線真的很多，否則 Notion 那種 5,000px 以內的長度比較容易讓人看完。
