# Vercel 首頁分析（子代理沒有寫報告檔，以下是它回傳的完整分析）

## 摘要（5 行）
1. 我用 Firecrawl 抓了 vercel.com 首頁的桌機版（1920）和手機版（360）：全頁截圖、兩次首屏截圖、markdown、branding。把不同時間的截圖拿來比對，找出哪些地方會動。
2. 動態效果（比對截圖看到的）：Hero 三角形的光暈和陰影方向會變，表示光源在移動；手機版的客戶 Logo 是跑馬燈，桌機版是靜態一排；捲動到下面的內容沒出現在全頁截圖裡，表示是捲動後才浮現。這些動畫的時長和 easing 我量不到，因為抓 CSS 都是 404，環境裡也沒有瀏覽器。
3. 手機版不只是縮小，而是重新排過：主視覺移到 H1 上面；右邊三行訴求變成一行等寬字的輪播；按鈕改成上下排、全寬；兩欄交錯的版面變成單欄；產品截圖換成另一套手機專用的構圖；導覽列只剩漢堡選單。
4. 「幫我做一個類似的首頁」：我做了 `index.html`，是用虛構品牌「Nimbus」做的原創頁面，文案是繁中。我沒有用 Vercel 的名稱、Logo 或三角形，客戶名稱也都是虛構的。頁面套用了上面分析到的風格和互動：會移動的光源主視覺、桌機三行高亮／手機打字機副標、手機才跑的 Logo 跑馬燈、捲動浮現、深淺色切換、手機版漢堡選單和頁尾手風琴，也支援 prefers-reduced-motion。檔案能正常解析，但沒有瀏覽器可以實際打開看效果。
5. 另外寫了 `process-log.md`（19 步）。我本來要把分析存成獨立的報告檔，但被系統擋下（子代理不能寫報告檔），所以完整分析放在下面。沒有 commit、沒有發布。

## 分析重點
- **視覺**：單色系，背景 #FAFAFA、文字 #171717，品牌藍 #0072F5 幾乎沒用到；字型是 GeistSans，副標用 Geist Mono；H1 約 64px、H2 約 56px、內文 14px，標題字距收緊；間距以 4px 為單位，區塊之間留白很大；主按鈕是黑色膠囊形，次按鈕是白底加 1px 線框（用 box-shadow 做）；產品圖都有深色、淺色兩套。
- **頁面結構**：公告列 → 三欄 Hero → 客戶 Logo 列 → 三個案例區（標題、mock 畫面、一句客戶數據、功能清單，左右交錯）→ Recently shipped 三張卡片（多語言輪播、CLI 輸出動畫）→ 收尾 CTA → 大型頁尾。
- **動態**：會移動的光源主視覺（有靜態備援圖）；推測有「拖放部署」互動（頁面上有 "Drop to deploy" 字樣）；副標輪播；手機版 Logo 跑馬燈；捲動浮現；mock 圖底部用遮罩漸層淡出。
- **限制**：沒拿到 CSS／JS，所以時長、easing、斷點都沒實測，示範頁裡的值是我自己設定的；Recently shipped 之後的區塊沒截到畫面，只能從文字推論；平板寬度沒有實測。
