# Vercel 首頁：設計師摘要

> 研究日期 2026-10-01。這是 [完整研究報告](report.md) 的摘要，每一點都可以點進去看證據。

## 這個網站在做什麼
Vercel 的首頁對開發者介紹「給 agent 用的基礎設施」，用 Notion、Zapier、Mintlify 三個客戶案例分別對應三種用途，最後把訪客帶到「Deploy now」（自助）或「Talk to sales」（業務）。

## 最值得學的設計決定
1. **動態是可以拔掉的一層**：首屏先顯示一個平面的黑色三角形，約 3 秒後光暈圖層才用 1.2 秒淡入，之後光影一直緩慢變化。開啟「減少動態」時，光暈、logo 跑馬燈、副標換字全部消失，頁面仍然完整。好處是動畫永遠不擋內容。
   可信度：瀏覽器實測。→ [report §5 VP-01](report.md#vp-01-動態是可移除的加強層)
2. **手機把「並排」換成「輪播」**：桌機 Hero 右側並列三句短語、7 個客戶 logo 一字排開；到了平板和手機，三句變成同一行等寬字、每 3 秒左右用亂碼解碼的效果換一句，logo 變成 40 秒一輪的跑馬燈。內容一個都沒刪，只是改成輪流看。
   可信度：瀏覽器實測（換字的確切時長未量到）。→ [report §5 VP-06](report.md#vp-06-小螢幕把空間上的並列換成時間上的輪播)
3. **單欄化但不改順序，主要按鈕變全寬**：桌機三段案例左右交替，手機一律單欄、照「標題 → 產品畫面 → 數據 → 功能清單」排；頁尾 6 欄 → 3 欄 → 2 欄；兩側邊距始終 24px。手機上 Hero 的兩顆按鈕變成全寬上下堆疊（底部 CTA 例外，仍並排）。
   可信度：瀏覽器實測＋截圖。→ [report §5 VP-05](report.md#vp-05-多欄降成單欄時保留原本順序)、[VP-07](report.md#vp-07-手機上把主要動作放大成全寬)
4. **灰階建立層級，顏色只給系統訊號**：背景 #FAFAFA、文字 #171717、補充文字 #4D4D4D；常見寫法是「黑色主句＋灰色後半句」。主要畫面上看得到的藍色只出現在 focus 外框和頁尾的系統狀態列。
   可信度：瀏覽器實測。→ [report §5 VP-02](report.md#vp-02-灰階承擔層級彩度只給系統訊號)、[VP-03](report.md#vp-03-黑色主句灰色補充的兩段式文字)
5. **元件回饋小而快**：按鈕 hover 只在 150ms 內換底色，不放大也不位移；頁首捲動後只多一條 1px 底線。比較長的光暈動畫只留給三角形和展示卡片。捲動時各段落沒有測到進場動畫。
   可信度：瀏覽器實測。→ [report §5 VP-08](report.md#vp-08-介面回饋小而快只變色不位移)

## 代價與不要照抄的地方
- 桌機 Hero 的完整說明要 hover 才看得到，手機訪客完全看不到。
- 手機上的跑馬燈和換字讓畫面一直在動，資訊要等才能看完；不適合重要內容。
- 首屏的光暈約 3 秒後才出現，第一印象其實是靜態版本。
- 三角形、文案、客戶 logo 與產品截圖都是 Vercel 的品牌資產，只能借結構和節奏。

## 還不確定的事
- 三角形光暈會不會跟著滑鼠動，還沒驗證（需要固定游標長時間錄影）。
- 手機副標的換字時長只用 200ms 取樣估計，不能直接當動畫規格。
- 截圖下半頁空白，下半頁只能靠逐段截圖；深色模式完全沒拍。
